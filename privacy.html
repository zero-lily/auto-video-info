This Privacy Policy explains how Auto_Video ("Auto_Video", "the application") accesses, uses, stores, and deletes information when using YouTube API Services.

1. Nature of the application

Auto_Video is a private/internal video production and publishing application operated locally and exclusively by its owner. It is not offered to external users and is not provided as a public service. Where the application is used with a YouTube channel, access is obtained only through Google OAuth 2.0 authorization granted for a channel managed by the owner.

2. Use of YouTube API Services

Auto_Video uses YouTube API Services. When the owner authorizes or uses YouTube-related functions in Auto_Video, that use is also subject to the YouTube Terms of Service. Google's privacy practices are described in the Google Privacy Policy.

3. Information that may be accessed or stored

Depending on the functions used and the permissions granted by the owner, Auto_Video may access or store the minimum information reasonably necessary to perform authorized YouTube operations, including:

  • OAuth access and refresh tokens issued by Google for the authorized account or channel;
  • identifiers and basic information needed to identify an authorized YouTube channel;
  • video metadata supplied for an upload or management operation, such as title, description, privacy status, and related identifiers;
  • YouTube API responses needed to confirm or manage an authorized operation, such as uploaded video IDs and operation status;
  • public YouTube metadata retrieved through the API when required by an enabled application function.

Auto_Video does not request, collect, or store Google or YouTube account passwords.

4. How the information is used

Information accessed through YouTube API Services is used only for functions configured by the owner, including authenticating access, identifying the target channel, uploading videos, applying selected video metadata, confirming API operations, and maintaining operational records needed for the publishing workflow.

YouTube API data is not used for unrelated advertising, profiling, resale, or any service provided to third parties.

5. Sharing and disclosure

Auto_Video does not sell YouTube API data or authorized user data. Information is transmitted to Google/YouTube as necessary to perform the requested YouTube API operation. Data is not shared with unrelated third parties, except where required by law or where transmission is technically necessary to perform a service explicitly configured by the owner.

6. Local storage and security

The application is primarily operated locally. Credentials and operational data are stored only to the extent necessary for authorized application functions. Reasonable administrative and technical measures are used to protect stored credentials and data from unauthorized access, use, or disclosure.

7. Retention and deletion

YouTube API data is retained only for as long as needed for the authorized purpose and is refreshed or deleted where required by the applicable YouTube API Services policies. When authorization is revoked or deletion of stored authorized data is requested, associated authorized data will be deleted as soon as reasonably possible and no later than 7 calendar days, except to the extent retention is required by applicable law.

Deleting information stored by Auto_Video does not delete information stored by YouTube. Content hosted on YouTube must be deleted using YouTube or another authorized client that supports that action.

8. Revoking Google / YouTube authorization

Authorization granted to Auto_Video can be revoked through Google's security settings: Google account permissions.

After authorization is revoked, Auto_Video will no longer use that authorization for new YouTube API requests, and stored authorized data associated with that authorization will be handled as described in the retention and deletion section above.
